# ConfFind 会议资料检索站

公开会议资料（日程 / PPT / 摘要 / 附件）元数据的导入、检索与管理演示站。
**纯 Python 标准库实现**（`http.server` + `sqlite3`），零第三方依赖。

## 快速开始

```bash
cd conffind
python3 app.py          # 首次启动自动建表并导入示例数据
# 打开 http://127.0.0.1:8000
```

后台：`/admin`，演示密码 `admin123`（可用环境变量 `ADMIN_PASSWORD` 修改，端口用 `PORT`）。

## 功能

**前台**
- 关键词搜索（标题 / 文件名 / 议程 / 摘要），并按 **主题、讲者、文件类型**（PPT/摘要/附件/视频/论文）筛选
- 会议库与会议详情页：按 日期 → 主题 → 议程 → 文件 展示完整日程与文件结构
- 文件详情页：元数据（大小/页数/语言/来源/SHA1）、在会议中的位置树、**相关会议**（同主题 + 同讲者）
- 讲者页：出席议程与公开资料汇总

**后台**
- 搜索热词 TOP20（全部时间 / 近 7 天）与最近搜索记录
- 条目管理：按关键词/状态筛选，**屏蔽 / 解除屏蔽**不合规条目（需填写原因）
  - 被屏蔽条目从前台搜索、会议日程中隐藏，详情页返回 410 并展示屏蔽原因
- 一键重新导入 `data/import.json`（幂等，不覆盖屏蔽状态）

## 数据导入

```bash
python3 seed.py                  # 生成示例元数据 data/import.json
python3 importer.py [json路径]   # 导入（幂等：按 会议名+年份 / 议程标题 / 文件名 去重）
```

JSON 结构：`conferences[] → sessions[] → speakers[] / files[]`，
文件类型支持 `ppt / abstract / attachment / video / paper`。

## 文件说明

| 文件 | 说明 |
|---|---|
| `app.py` | HTTP 服务与路由（前台检索 + 后台管理） |
| `db.py` | SQLite 表结构（会议/议程/讲者/文件/搜索日志） |
| `repo.py` | 查询层 |
| `views.py` | 服务端渲染页面 |
| `importer.py` | 元数据导入器 |
| `seed.py` | 示例数据生成器 |
